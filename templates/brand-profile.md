# Brand profile

Copy this file to the root of a project as `brand.md` (or `.claude/brand.md`) and fill
it in. Every skill in the rule library reads it before producing customer-facing work.
Delete sections that do not apply. Leave a line as `unknown` rather than guessing;
the skills will flag it.
